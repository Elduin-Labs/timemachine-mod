## 1.1.0

- **Roll** button on the dial: it picks a version for you, anywhere but where you already are.
- **Really go there**: for versions installed on this computer as real, playable clients, the
  machine now quits Minecraft and opens the genuine old game instead of imitating it. The panel
  names the client you would actually get, and the button asks twice before it does it.
- A real 1.0.0 is now one of the clients **Really go there** knows how to open, alongside the
  alpha, the betas, 1.9 and 1.12.2.
- The machine is now crafted from four oak planks, in the corners of the grid.
